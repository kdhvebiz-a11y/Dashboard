# 컨설팅 대시보드 v10.2 — 원본 대조 반영

이번 수정본은 전달받은 v9 서버 코드와 index.html을 기준으로 만들었습니다. 2026-09-14 오전 7:24(KST), 기존 Google 운영 주소에 배포 버전 13으로 반영했습니다. 주소와 접근 권한은 유지했습니다.

## 먼저 화면 확인

[수정본 미리보기](http://127.0.0.1:4176/)

이 미리보기는 이 PC에서 실행 중인 서버가 켜져 있을 때 사용할 수 있습니다. 현재 운영 중인 v9의 통계·말 전체 보고 범위를 읽고, 이전 서버에서는 연도별 원장만 별도로 읽습니다. 두 데이터의 갱신 시각을 대조 파일에 기록합니다. 원본 시트를 바꾸지 않습니다.

2026-09-11 통계 AB193:AO210, 말 AY386:BK406을 로그인된 원본 화면에서 직접 복사해 데이터 응답과 대조했습니다. 12개월의 전체 문의·발전 문의·실제 미팅·용량도 자동 대조합니다.

## 이번 반영 내용

- 축소된 이전 데이터 연결을 통계·말의 전체 보고 범위로 교체했습니다.
- 전체 문의는 통계 194행, 전체 사업 문의와 유입별 사업 문의는 195~197행을 사용합니다. 195행은 자가소비·임대 등을 포함하므로 기존 집계값은 유지하고 이름만 바로잡았습니다.
- 미팅 목표는 말 CI1의 100건을 사용합니다. 용량 목표(kW)를 건수 목표로 사용하지 않습니다.
- 보고표와 담당자·용량 구간·달력 미팅일 원장에 차이가 있으면 요약·실제 미팅·보고서에 ‘원본 대조’로 표시합니다.
- 담당자 표와 월별 추세가 같은 집계를 사용합니다.
- 발전사업 미팅 전환율은 발전사업 미팅÷전체 사업 문의로 계산합니다. 다른 사업형태 미팅을 분자에 섞지 않습니다.
- 원본 말 보고 주차는 월 경계를 넘거나 예정 건을 포함할 수 있으므로 달력 미팅일 원장과 구분합니다.
- 생성된 서버의 데이터 캐시는 최대 5분입니다. 새로고침은 캐시를 무시하고 다시 읽습니다. 자동 갱신 옵션은 화면에서 별도로 켭니다.

교체 직전 Google 코드 두 파일은 output/backup-2026-09-13T22-11-29-905Z 폴더에 백업되어 있습니다. 자동알림장 등 다른 스크립트와 원본 시트는 수정하지 않았습니다. 큰 연도별 데이터를 HTML에 직접 넣지 않고 화면 표시 후 비동기로 읽도록 초기 로딩을 개선했습니다.

첫 화면에는 네 가지 숫자를 보여줍니다: 전체 문의, 전체 사업 문의, 해당 문의에서 이어진 미팅, 해당 기간에 실제 진행한 미팅. 세부 조건과 원장은 필요할 때 펼칩니다.

기간은 연도·월 선택, 이번 달, 지난달, 이번 분기, 연 누적으로 변경합니다. ‘기간 골라 비교’를 펼치면 여러 월·분기를 선택할 수 있습니다. 초기화는 기본 연도·이번 달·전체 조건으로 돌아갑니다.

## Google Apps Script 적용

압축파일의 `index.html`과 `대시보드.gs`가 배포용 완성 파일입니다. template 파일이나 extension 파일을 별도로 붙이지 않습니다.

1. 기존 Apps Script 프로젝트에서 현재 `index.html`과 `대시보드.gs`를 먼저 백업합니다.
2. 해당 두 파일의 내용을 수정본으로 교체하고 저장합니다. 기존의 자동알림장 등 다른 파일은 그대로 둡니다.
3. 배포 → 배포 관리 → 기존 웹앱 선택 → 수정에서 새 버전을 선택해 배포합니다. 기존 배포를 갱신하면 주소가 유지됩니다.
4. 운영 주소를 다시 열어 왼쪽 아래 `v10.2 · 원본 대조` 표시와 첫 화면 네 개의 주요 지표를 확인합니다.
5. 30분마다 백데이터 캐시를 갱신하려면 기존 `캐시채우기` 시간 트리거를 확인합니다. 트리거가 없다면 `설치` 함수를 한 번 실행합니다. 브라우저 화면은 자동 갱신 옵션으로 따로 새로 읽습니다.

배포 방식 참고: [Google 공식 문서 — 기존 배포 갱신](https://developers.google.com/apps-script/concepts/deployments#edit_a_versioned_deployment).

## 집계 기준과 제한

- 문의월의 미팅은 통계 미팅 원장에서 상담번호의 접수월로 묶습니다. 미래 미팅일과 날짜 미기재 건은 진행 실적에서 제외합니다.
- 부서 전체 실제 미팅과 용량은 말 시트의 활동월 집계를 우선합니다. 월별 집계와 날짜별 원장에 차이가 있으면 대조 안내를 표시합니다.
- 컨설팅 담당자는 미팅을 잡은 담당자, 현장 담당자는 미팅을 진행한 담당자입니다. 필터를 동시에 적용할 수 있습니다.
- 연도 시트는 2025년 이후 숫자 이름을 자동 탐색합니다. 과거 연도는 연도별 문의 원장을 사용하며 현재 통계·말 시트와 집계 방식이 다를 수 있습니다. 연도 원장의 유입은 소개 상태 여부, 법인은 상담번호의 접두어로 분류합니다. 부서의 입력 규칙과 함께 확인해야 합니다.
- 현재 통계·말 요약에서 나눌 수 없는 문의 교차 조건은 ‘—’로 표시합니다. 법인×소개 교차 문의를 0건으로 단정하지 않습니다.
- 평균 용량은 합계 용량÷합계 건수로 계산합니다. 용량 구간 분석에서 용량 미기재·0인 건은 분리합니다.
- 문의 목표는 말 BT18의 월 전체 1500건, 발전 마케팅 700건+소개 87건 설정이며 미팅 목표는 CI1입니다. 목표를 연도·월별로 변경할 수 있습니다. 변경 목표와 보고 의견은 해당 브라우저에만 저장됩니다. 조직 전체 공유 목표는 별도 서버 저장 연결이 필요합니다. 담당자 등 상세 필터를 적용한 화면에서는 부서 목표를 개인 목표로 사용하지 않습니다.
- 실제 계약은 지정 PC 폴더의 RPS 프로젝트 엑셀을 읽어 연결했습니다. 상세 기준과 다음 파일 갱신 방법은 `계약자료_연결안내.md`를 참조하세요. 실제 계약일과 엑셀 보고 월을 구분하며, 공사금액은 VAT 제외 기재분을 합산합니다. 문의 시트의 계약 상태와는 별도 데이터입니다.
- 보고서는 포함 항목을 선택하고 인쇄 창에서 PDF로 저장할 수 있습니다. 원장과 비교표는 CSV로 내려받습니다.
